# ADR-006：用户内容一律软删除

**状态**：已接受 ｜ **驱动特征**：安全性（可追责）

## 背景
问答内容之间存在引用关系（回答引用问题、评论引用回答、声誉流水引用回答），物理删除会造成悬挂引用；
同时校园场景需要保留争议内容以供教师复核。

## 决策
问题、回答使用 `deleted_at` 标记删除；已删除内容不出现在列表、详情与搜索投影中，但保留在库中；
删除权限：作者（问题需无回答）或课程教师/助教/管理员；删除动作写审计日志。

## 后果
- 正面：引用完整、可复核、可恢复；声誉流水不会因内容删除而失效。
- 负面：所有查询都必须显式带 `deleted_at IS NULL`（已在读模型与投影中统一处理）；需要按学期清理归档。

## 被否决的替代方案
- 物理删除：不可恢复、破坏引用、无法追责。
